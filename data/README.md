# Dataset Information

This folder contains the datasets used for the Hyperliquid Sentiment & Trader Behavior Analysis project.

---

## 1. Bitcoin Fear & Greed Dataset

**File Name:** `fear_greed_index.csv`

### Description

This dataset contains historical Bitcoin market sentiment data represented using the Fear & Greed Index.

It includes:

* Daily sentiment classification
* Fear & Greed score values
* Historical market psychology indicators

### Dataset Link

[Fear & Greed Dataset](https://drive.google.com/file/d/1I9K780IvE8Tq8KKJlgKvbArdq7Qv-wIF/view?usp=sharing&utm_source=chatgpt.com)

### Key Columns

* `date`
* `classification`
* `value`

---

## 2. Hyperliquid Historical Trader Dataset

**File Name:** `historical_data.csv`

### Description

This dataset contains historical trading activity from Hyperliquid traders.

It includes:

* Trade execution details
* Position sizes
* Profit & Loss metrics
* Trading direction
* Transaction metadata
* Trader activity behavior

### Dataset Link

[Historical Trader Dataset](https://drive.google.com/file/d/1_00HHhRC46BwExnNjM1j6rr8_QBUh1U-/view?usp=sharing&utm_source=chatgpt.com)

### Key Columns

* `Account`
* `Execution Price`
* `Size USD`
* `Closed PnL`
* `Side`
* `Timestamp IST`
* `Fee`

---

# Usage

These datasets are used for:

* sentiment analysis,
* behavioral finance analysis,
* trader segmentation,
* profitability analysis,
* and risk-performance evaluation.

The datasets are merged using daily timestamps to analyze how market sentiment influences trader behavior and trading outcomes.
